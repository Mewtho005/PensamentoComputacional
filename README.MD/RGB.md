Trabalho de RGB:
Eu montei um circuito com Arduino, três potenciômetros e um LED RGB.
Liguei os potenciômetros nas entradas A1, A2 e A3 para ler os valores deles.
No código, eu fico lendo esses valores o tempo todo e uso “mapear” para transformar em uma escala de 0 a 255. Depois, envio esses valores para os pinos 9, 10 e 11, que controlam o LED.
Assim, quando eu giro cada potenciômetro, eu mudo a intensidade de uma cor e consigo formar várias cores diferentes no LED RGB.
